# 📖 문장 마스터 PRO (Sentence Master PRO)

스마트 영어 문장 완벽 암기 웹 애플리케이션입니다.

## ✨ 주요 기능
- **5단계 점진적 암기 시스템**: 끊어 읽기 → 단어 조합 → 핵심 빈칸 → 초성 힌트 → 통문장 타이핑
- **📊 선생님 구글 스프레드시트 실시간 연동**: 학생 학습 완료 시 날짜/학생명/정답률/오답목록 자동 기록
- **🔗 학생 배포용 자동 연동 링크 (`?sheet=...`)**: 학생은 별도 설정 없이 링크 접속만으로 자동 연동
- **📋 카카오톡/문자 제출용 결과 리포트 복사**: 1클릭으로 정돈된 성적표 클립보드 복사
- **원어민 음성 듣기 (TTS)**: Web Speech API를 활용한 자연스러운 영어 발음 및 배속(0.8x/1.0x/1.2x) 제어
- **자체 신디사이저 효과음**: Web Audio API로 정답/오답/콤보/승리 사운드 내장
- **키보드 편의성**: Enter 키 채점 및 오답 Diff 상세 비교 하이라이트
- **힌트 & 오답 노트**: 2초 정답 엿보기, 스킵 및 '틀린 문장만 다시 복습하기' 모드
- **원클릭 추천 문장 팩**: 일상 회화, 여행, 비즈니스, 영화 명대사 프리셋 내장 & 엑셀 스마트 붙여넣기 지원
- **다크/라이트 테마 & 폭죽 애니메이션**: 다크 모드 전환 및 전체 마스터 시 Confetti 축하 효과
